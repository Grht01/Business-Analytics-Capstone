This repository holds the data extract, estimation code, and output tables behind the capstone report. It exists so that every statistic in the report can be traced back to the command that produced it. Running the two scripts below on the supplied data reproduces every table and figure in Chapter IV and every appendix table.

What the study asks. Do three properties of a tweet predict whether it takes a believer or a denier position on climate change: how positive it sounds, how aggressive its language is, and how unusual the local temperature was? And does the economic development level of the country it comes from change how strongly each of those works?

Repository contents

FileWhat it is
Stance_sample_data.zip The analytic data extract. A stratified random draw of 250,000 tweets from the Climate Change Twitter Dataset, taken with seed 42. Fourteen columns per tweet, covering stance, sentiment, aggressiveness, inferred gender, local temperature anomaly, coordinates, country, and World Bank income group.
analysis.R Main estimation script. Builds the analytic sample, estimates Equations 1 to 4, computes diagnostics and average marginal effects, and runs robustness checks R1 to R4. Ends with a self-verification block that checks its own output against the values reported in the report.
placebo_permutation_test.R Falsification test. Reassigns the developed and developing labels across the 142 countries 500 times and builds an empirical null distribution for each interaction coefficient.
results.zip Output tables written by the scripts, as CSV.

How to reproduce

  1. Clone or download the repository and unzip Stance_sample_data.zip so that Stance_sample_data.csv sits beside the two scripts.
  2. Open R, set that folder as the working directory.
  3. Run the main estimation. Missing packages install automatically. 
    source("analysis.R")
    Expect 15 to 45 minutes. The country random-intercept model in Equation 4 is the slow step and can be skipped by setting RUN_GLMER <- FALSE.
  4. Run the falsification test. 
    source("placebo_permutation_test.R")
    Expect 4 to 8 minutes at 500 permutations.
  5. Output lands in a results/ folder. The final section of analysis.R prints a verification table comparing its own figures against those in the report; every row should read OK.

Guard rails. Both scripts stop immediately if the input is not 250,000 rows or the analytic sample is not 196,406 rows, so loading the wrong file fails loudly rather than producing plausible but wrong numbers.

Method in brief

The outcome is binary, believer against denier, so estimation is by binary logistic regression. Country economy and every interaction built from it are country-level quantities applied to tweet-level observations, so tweets from the same country are not independent with respect to the moderator. Inference therefore uses country-clustered standard errors alongside a country random intercept, and moderation is read through average marginal effects rather than raw interaction coefficients.

196,406 tweets 142 countries 2006 to 2019 179,872 developed 16,534 developing

Marginal effects are for developed economies, in percentage points on the probability of a believer stance. Odds ratios are from the interaction terms under country-clustered inference. All six decisions are identical under the pooled, clustered, fixed effects and random intercept specifications.

A result worth stating plainly

The model carries real information about the ordering of cases, with an area under the curve of 0.700. At the conventional 0.5 classification threshold it nonetheless identifies no deniers at all, and its accuracy of 0.9152 is exactly the believer base rate. Association at population scale and usable detection are different achievements, and this study delivers the first without the second.

Data provenance

The data here is a derived sample, not the original corpus. It comes from the Climate Change Twitter Dataset compiled and released by Effrosynidis, Karasakalidis, Sylaios and Arampatzis, who documented it in Expert Systems with Applications (2022) and reported the descriptive analysis in PLOS ONE (2022). All credit for the underlying collection and annotation belongs to them. Anyone reusing this extract should cite the original dataset and check its licence terms, and should treat every label in it as a machine classification carrying error rather than as verified ground truth.
